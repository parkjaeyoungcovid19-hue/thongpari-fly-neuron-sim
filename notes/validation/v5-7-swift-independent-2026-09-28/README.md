## 계약에 부합한 항목 (코드 검토)

- V5.7 카드: 텔레메트리 표시만 한다. 클릭은 출처만 보여 주며 명령이나 자극을 만들지 않는다. 배고픔은 미지원으로 표시하고, 비유한 값은 “—”로 표시한다. 진단에 쌍둥이 sim 비교와 음성 대조가 있다.
- 당 GRN/MN9: `taste_sugar`는 식별된 GRN에만 들어가고 MN9는 읽기 전용이다. readout을 끈 경우의 bit-identical 대조와 냄새만 준 음성 대조가 진단에 있다.
- 도구 입력: G/F는 키 반복으로 발사되지 않고 held movement에도 들어가지 않는다. 총 장착 상태는 성공 ACK에서만 반영한다.
