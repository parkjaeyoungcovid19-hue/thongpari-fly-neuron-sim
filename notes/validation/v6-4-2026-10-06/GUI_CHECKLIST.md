# V6.4 GUI 확인 목록 (사용자 직접)

Claude는 이 환경에서 앱 창을 조작할 수 없으므로(팀 플랜 Computer Use 차단) 아래 항목은 미확인이다. 실행: `Virtual Fly Lab.command` 또는 `dist/` 앱. 각 항목에 통과/실패와 메모를 남기면 된다.

| # | 동작 | 기대 결과 |
|---|---|---|
| 1 | 왼쪽 ‘물체 놓기’ → 종류 **경사로 (파리가 오를 수 있음)** → 만들기 | 갈색 판이 낮은 쪽 끝을 잔디에 붙인 채 15° 기울어져 생긴다. ‘물체 수’에 `ramp 1/4` |
| 2 | 경사로를 4개 만든 뒤 한 번 더 만들기 | 아무것도 생기지 않고 “경사로 자리를 모두 쓰고 있습니다 (4/4개) — … 하나를 지우면 다시 만들 수 있습니다”가 주황색으로 표시 |
| 3 | 위쪽 ‘편집’ → 목록에서 경사로 선택 → **기울기** 탭 | 칸에 현재 기울기(15), ‘현재 —’ 줄에 `기울기 15.0°`. 노란 외곽선이 화면 속 기울어진 판과 겹친다 |
| 4 | 기울기 칸에 30 입력 → Return | “적용됨 · 30”. 판이 더 서고, 잔디에 닿은 낮은 쪽 모서리는 제자리 |
| 5 | 3D 화면의 ∠ 핸들을 위로 끌었다 놓기 | 끄는 동안 “초안”, 놓으면 적용. 45°를 넘지 않는다 |
| 6 | 기울기 칸에 50 입력 → Return | 적용되지 않고 오류 문구. 판은 그대로 |
| 7 | 상자를 선택 | 기울기 탭이 비활성, 안내 “기울기는 경사로만 바꿀 수 있습니다…” |
| 8 | 경사로 복제 | 같은 기울기의 복제본이 같은 자리에 생기고 선택이 옮겨간다. 4개가 찬 상태면 “자리가 모두 찼습니다” |
| 9 | 참여 모드에서 경사로를 잡기(클릭) | 잡히지 않는다 (고정 지형) |
| 10 | 파리 앞에 경사로를 두고 지켜보기 | 파리가 걸어 들어가면 다리로 올라탄다. 걷는 방향은 뇌가 정하므로 오르지 않을 수도 있다 — 다리가 판을 **뚫고** 지나가면 실패 |
| 11 | 파리가 경사로 위에 있을 때 상태줄 body Hz·배율 | 떨어지는 것이 정상(측정상 body step 약 +45%). 멀리 있으면 거의 차이 없음 |

GUI에서 판의 색·두께·조작감이 마음에 들지 않으면 그 내용을 알려 주면 된다.
