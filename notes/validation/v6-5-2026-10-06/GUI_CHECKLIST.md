# V6.5 GUI 확인 목록 (사용자 직접)

Claude는 이 환경에서 앱 창을 조작할 수 없으므로(팀 플랜 Computer Use 차단) 아래 항목은 미확인이다. 실행: `Virtual Fly Lab.command` 또는 `dist/` 앱(다시 패키징 필요). 왼쪽 목록에서 **감각** 페이지를 연다. 각 항목에 통과/실패와 메모를 남기면 된다.

화면 밖 렌더 PNG(`environment-*.png`)는 배치만 보여 준다. 그 렌더에서는 슬라이더 손잡이 위치가 틀리게 그려지는데(값 자체는 맞음: 출력의 `slider values` 줄), 실제 창에서도 그런지는 아래 1·6번에서 확인한다.

| # | 동작 | 기대 결과 |
|---|---|---|
| 1 | 페이지를 연다 | 맨 위 ‘지금 파리 위치의 값’이 계속 바뀐다(몸 시각이 증가). 슬라이더 손잡이가 적용값 위치에 있다 |
| 2 | 온도 방식 → ‘온도 감각 뉴런에 전달’, 온도 슬라이더를 35로 끈다 | 끄는 동안 ‘보내는 중’ 줄, 놓으면 ‘적용됨: 35.0 °C’. 맨 위 ‘감각 전류 따뜻’이 0보다 커진다 — **적용됨이 뜬 뒤에만** 바뀌어야 한다 |
| 3 | 온도 슬라이더를 좌우로 빠르게 여러 번 흔든 뒤 놓기 | 끝나면 적용값이 마지막 위치와 같다. 앱이 버벅이지 않는다 |
| 4 | 온도 칸에 50 입력 → Return | 보내지 않고 빨간 문구 “10–40 사이 숫자…” |
| 5 | 바람 세기 슬라이더를 0.6으로 | ‘적용됨: 세기 0.60 · … · 계속 부는 중’. 맨 위 ‘바람’ 줄에 파리 기준 방향과 더듬이 전류 C/E가 나온다 |
| 6 | 방향 다이얼을 위쪽으로 돌린다 | 칸이 90. 3D 화면을 위에서 봤을 때 +Y 쪽으로 분다. 맨 위 줄의 ‘파리 기준’ 말이 파리가 바라보는 방향과 맞는다 |
| 7 | 바람 세기 1, 옆바람에서 ‘몸을 실제로 밀기’를 끈다/켠다 | 켜면 파리가 바람 쪽으로 눈에 띄게 밀린다(1초에 약 9 mm), 끄면 멈춘다. 정면 바람 0.7 이상이면 서 있는 파리가 뒤로 넘어갈 수 있다(허용됨) |
| 8 | ‘한 번 (ms)’ 3000 → ‘한 번 불기’ → 바로 세기 슬라이더를 움직인다 | 빨간 문구 “시간 제한 바람이 부는 중…”, 바람은 그대로. ‘바람 끄기’를 누르면 바로 멈춘다 |
| 9 | ‘바람 끄기’ | ‘적용됨: … 꺼짐’, 맨 위 바람 줄 ‘파리 위치에 없음’ |
| 10 | 왼쪽 눈 가림을 100%로 | ‘적용됨: 왼쪽 눈 100% 가림’, 맨 위 ‘눈 밝기 왼’이 1초 안에 0.00 근처 |
| 11 | 먹이 종류 ‘치즈’ → ‘파리 앞 15 mm에 놓기’ | ‘놓았습니다’, 3D 화면 파리 앞에 치즈. ‘먹이 1/8개 — 치즈’, 맨 위 냄새 값이 올라간다. 8개가 찬 뒤 한 번 더 누르면 자리 부족 문구 |
| 12 | ‘실험’ 페이지 → 초기화 → ‘세계’ | 온도 25·기록만, 바람 꺼짐, 눈 0%로 슬라이더가 돌아온다 |
| 13 | 언어를 English로 바꿨다가 되돌리기 | 패널 문구가 바뀌고, 적용값·체크 상태가 유지된다 |
| 14 | 물리 시뮬레이터 없이(`--flygym` 없이) 실행 | 온도는 바로 바뀌고 ‘(뇌 쪽만, 물리 시뮬레이터 없음)’. 바람·눈 가림 컨트롤은 비활성 |

조작감(슬라이더가 끊기는지, 다이얼 방향이 헷갈리는지)이 마음에 들지 않으면 알려 주면 된다.
